# Frontend Development

Start the Superset frontend development server for React/TypeScript development.

## Usage

```
/frontend-dev
```

## What it does

- Navigates to the superset-frontend directory
- Installs dependencies if needed
- Starts the development server on port 9000
- Handles the React/TypeScript build process

## Context

The Superset frontend uses React with TypeScript. The dev server runs on port 9000 by default and provides hot-reloading for development.
